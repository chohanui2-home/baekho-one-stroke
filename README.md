# 백호의 한붓그리기

점과 점을 잇는 선을 **한 번도 떼지 않고, 같은 선을 두 번 지나지 않게** 모두 그으면 완성되는 퍼즐 게임입니다.
**4단계, 모두 87문제**가 들어 있어요.

**바로 하기:** https://chohanui2-home.github.io/baekho-one-stroke/

## 게임 방식

- 같은 선을 두 번 지나지 않고, 한 번에 모든 선을 이어 보세요. (연필을 떼면 끝!)
- 점을 **차례로 눌러도** 되고, 점에서 시작해 **손가락으로 쭉 끌어도** 됩니다. 끌고 있는 동안에는 지금 점에서 손가락까지 미리보기 선이 보여요.
- 위쪽 **◀ 이전 / 다음 ▶** 으로 옆으로 넘기면서 풀 수 있어요. 문제 목록이 길게 펼쳐지지 않아서 한 화면에서 다 됩니다.
- 가운데 **번호(예: `1-1 (1 / 13)`)** 를 누르면 `1~25` · `26~28` 처럼 **그 단계의 문제 수에 맞춘** 구간 탭과 5×5 번호판이 열려서 47번 같은 멀리 있는 문제도 바로 갈 수 있어요. (평소에는 접혀 있어요.)
- **되돌리기** 마지막에 그은 선 하나를 취소해요. (출발점만 찍힌 상태에서는 출발점을 해제)
- **처음부터** 지금 문제를 처음 상태로 돌려요.
- 한 문제를 다 이으면 `완성! 모든 선을 한 번에 이었어요.` 와 ✓ 를 **잠깐(약 0.5초)** 보여 준 뒤 **저절로 다음 문제로 넘어갑니다**. (1단계 마지막 문제를 끝내면 2단계 1번으로, 4단계 마지막 문제는 그대로 멈춰요.) 넘어가기 전에 `이전`·`다음`·단계·문제를 직접 고르거나 `되돌리기`·`처음부터`를 누르면 자동 넘김이 취소되어 엉뚱한 문제로 튀지 않아요.
- **힌트 보기** 지금 상태에서 끝까지 그을 수 있는 길을 계산해 출발점(시작 전) 또는 다음 1~2수를 점선과 화살표로 보여 줘요. 이미 막힌 길이면 "지금 길은 끝까지 갈 수 없어요! '되돌리기'로 한두 칸 돌아가 보세요."라고 알려 줍니다.
- 점수·타이머·별점 같은 것은 없어요. 순서대로 하지 않아도 되고, 아무 문제나 골라서 풀면 됩니다.

## 학교 행사 공용 태블릿에서 쓰기

- **아무것도 저장하지 않습니다.** 브라우저 저장소(localStorage)를 전혀 쓰지 않아서, 새로고침하거나 다른 아이가 이어서 열어도 **언제나 1단계 1번, 빈 판**에서 시작해요.
- **문제를 열 때마다 빈 판**입니다. 다음 문제·다른 번호·다른 단계로 넘어가면 앞사람이 그은 선은 남지 않고, 단계 탭은 이미 푼 번호를 건너뛰지 않고 항상 **1번**부터 열려요.
- 같은 화면을 보는 동안에만 ✓ 와 단계별 `3/13` 같은 개수가 남아서, 한 아이가 한 단계를 이어서 풀 때 자기 진행을 볼 수 있어요. 화면을 닫으면 사라집니다.

## 4단계 87문제

| 단계 | 이름 | 문제 | 선 개수 |
|---|---|---|---|
| 1 | 기본 | 13문제 | 9~11선 |
| 2 | 발전 | 21문제 | 12~14선 |
| 3 | 도전 | 25문제 | 15~17선 |
| 4 | 마스터 | 28문제 | 18~24선 |

87문제 모두 **하나로 이어진 도형**이고 **홀수점이 0개 또는 2개**라서 반드시 한붓그리기로 완성할 수 있어요.
쉬운 7~8선 도형은 빼고 **1단계부터 9선**으로 시작하며, 단계마다 한 단계씩 더 어려워집니다.
어떤 선도 다른 꼭짓점을 스치지 않고(비종점 거리 6 이상), 점 사이 간격도 12 이상이라 390px 폰에서도 손가락으로 누르기 편합니다.

## 겹치는 모양은 하나도 없어요

문제를 만든 뒤 **4단계 전체를 통틀어** 네 가지 검사를 모두 통과한 도형만 남겼습니다.

1. **같은 그림** — 좌표가 같은 도형은 하나만.
2. **돌리거나 뒤집은 그림** — 점·선의 연결 구조가 같은 도형(회전·좌우/상하 대칭 포함)은 하나만.
3. **위상 동형** — 선 위에 점 하나 더 찍은 것처럼, 차수 2 꼭짓점을 지운 뒤 같은 도형도 하나만.
   (점만 있는 정다각형은 꼭짓점 수가 다르면 다른 그림으로 봅니다 — 9각형과 12각형은 눈에 다르게 보이니까요.)
4. **눈으로 본 검수** — 모든 단계의 도형을 썸네일 시트로 그려 놓고 사람이 직접 보고, 크기만 바꿨거나 비슷해 보이는 쌍은 뺐습니다. 그래서 단계마다 문제 수가 100이 아니라 13~28개예요. **수를 채우려고 비슷한 도형을 넣지 않았습니다.**

`test_app.py`가 1~3번을 전수 검사하고(모든 문제 쌍을 비교), `gen.py`는 고른 도형 목록 `curate.json`을 그대로 따라 같은 결과를 다시 만듭니다.

## 특징

- **화이트·실버 백호 테마** — 밝은 회백색 바탕에 흰 카드, 먹색 선과 아이스블루 포인트.
- **한 화면 조작** — 390×844 스마트폰에서 제목·단계 탭·좌우 넘기기·퍼즐 판·3버튼이 스크롤 없이 들어옵니다.
- **모바일·태블릿 최적화** — 아이폰 안전 영역 여백, 손가락 터치 반경을 넉넉하게, 가로 넘침 없이 한 손 조작.
- **외부 리소스 0건** — 폰트·CDN·이미지·오디오를 하나도 불러오지 않는 단일 HTML. 파일 하나만 보내도 오프라인에서 그대로 열립니다.
- **저장 0건** — 공용 기기에 아무 기록도 남기지 않습니다.

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일 (외부 요청 0건)
- `app_template.html` — 빌드용 템플릿 (`__DATA__` 자리표시자 포함)
- `puzzles.json` — 87문제의 점 좌표와 선 목록 (설계 원본)
- `gen.py` — 문제 생성기 (고정 시드, 기하·오일러 검사 + 네 겹 중복 제거)
- `topo.py` — 도형이 같은지 판정하는 도구 (그래프 동형·위상 동형·회전/뒤집기/크기 무관 지문)
- `curate.json` — 눈으로 보고 고른 도형 목록 (해시)
- `build.py` — 퍼즐 주입·단일 파일 규칙 검사 후 `index.html`과 `dashboards/백호의-한붓그리기.html`에 같은 바이트로 기록
- `test_app.py` — 정적 규칙 + 87문제 수학·중복 전수 검증(모든 꼭짓점 차수가 2인 원형 다각형 0건 포함) + QuickJS로 실제 스크립트를 돌려 87문제 전체 완주·탭·드래그·되돌리기·힌트·단계/구간/번호 이동·빈 판 시작·저장 없음을 검사하는 자동 테스트

## 다시 빌드하기

```bash
python3 gen.py         # puzzles.json 다시 만들기 (같은 시드 + curate.json → 같은 결과)
python3 build.py       # index.html + dashboards/백호의-한붓그리기.html 생성
python3 test_app.py    # 자동 테스트
```
