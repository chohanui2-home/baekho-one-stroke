# 백호♡ 한붓그리기

점과 점을 잇는 선을 **한 번도 떼지 않고, 같은 선을 두 번 지나지 않게** 모두 그으면 완성되는 퍼즐 게임입니다.
**4단계 × 100문제, 모두 400문제**가 들어 있어요.

**바로 하기:** https://chohanui2-home.github.io/baekho-one-stroke/

## 게임 방식

- 같은 선을 두 번 지나지 않고, 한 번에 모든 선을 이어 보세요. (연필을 떼면 끝!)
- 점을 **차례로 눌러도** 되고, 점에서 시작해 **손가락으로 쭉 끌어도** 됩니다. 끌고 있는 동안에는 지금 점에서 손가락까지 미리보기 선이 보여요.
- 위쪽 **◀ 이전 / 다음 ▶** 으로 옆으로 넘기면서 풀 수 있어요. 문제 목록이 길게 펼쳐지지 않아서 한 화면에서 다 됩니다.
- 가운데 **번호(예: `1-1 (1 / 100)`)** 를 누르면 `1~25` · `26~50` · `51~75` · `76~100` 구간 탭과 5×5 번호판이 열려서 47번 같은 멀리 있는 문제도 바로 갈 수 있어요. (평소에는 접혀 있어요.)
- **되돌리기** 마지막에 그은 선 하나를 취소해요. (출발점만 찍힌 상태에서는 출발점을 해제)
- **처음부터** 지금 문제를 처음 상태로 돌려요.
- **힌트 보기** 지금 상태에서 끝까지 그을 수 있는 길을 계산해 출발점(시작 전) 또는 다음 1~2수를 점선과 화살표로 보여 줘요. 이미 막힌 길이면 "지금 길은 끝까지 갈 수 없어요! '되돌리기'로 한두 칸 돌아가 보세요."라고 알려 줍니다.
- 점수·타이머·별점 같은 것은 없어요. 순서대로 하지 않아도 되고, 아무 문제나 골라서 풀면 됩니다. 마친 문제에는 은은한 ✓ 표시가 남아요.

## 4단계 400문제

| 단계 | 이름 | 문제 | 선 개수 |
|---|---|---|---|
| 1 | 기본 | 100문제 | 7~9선 (우편봉투 · 왕관 · 삼각 격자 · 다각형 …) |
| 2 | 발전 | 100문제 | 10~12선 (이층집 · 나비 · 바람개비 · 별 · 사다리 …) |
| 3 | 도전 | 100문제 | 13~15선 (눈꽃 · 계단 · 문 · 겹친 다각형 …) |
| 4 | 마스터 | 100문제 | 16~20선 (큰 격자 · 별빛 · 복합 대칭 …) |

400문제 모두 **하나로 이어진 도형**이고 **홀수점이 0개 또는 2개**라서 반드시 한붓그리기로 완성할 수 있어요.
어떤 선도 다른 꼭짓점을 스치지 않고, 점 사이 간격도 손가락으로 누르기 편하게 넉넉합니다.
(자세한 조건은 게임 아래 "한붓그리기가 되는 조건" 카드에 적어 두었습니다.)

## 특징

- **화이트·실버 백호 테마** — 밝은 회백색 바탕에 흰 카드, 먹색 선과 아이스블루 포인트.
- **한 화면 조작** — 390×844 스마트폰에서 제목·단계 탭·좌우 넘기기·퍼즐 판·3버튼이 스크롤 없이 들어옵니다.
- **모바일·태블릿 최적화** — 아이폰 안전 영역 여백, 손가락 터치 반경을 넉넉하게, 가로 넘침 없이 한 손 조작.
- **완료 표시만 저장** — 마친 문제의 ✓만 브라우저에 저장돼요. 점수나 기록은 저장하지 않습니다.
- **외부 리소스 0건** — 폰트·CDN·이미지·오디오를 하나도 불러오지 않는 단일 HTML. 파일 하나만 보내도 오프라인에서 그대로 열립니다.

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일 (외부 요청 0건)
- `app_template.html` — 빌드용 템플릿 (`__DATA__` 자리표시자 포함)
- `puzzles.json` — 400문제의 점 좌표와 선 목록 (설계 원본)
- `gen.py` — 400문제 생성기 (고정 시드, 기하·오일러 조건 검사 포함)
- `build.py` — 퍼즐 주입·단일 파일 규칙 검사 후 `index.html`과 `dashboards/백호-한붓그리기.html`에 같은 바이트로 기록
- `test_app.py` — 정적 규칙 + 400문제 수학 전수 검증 + QuickJS로 실제 스크립트를 돌려 400문제 전체 완주·탭·드래그·되돌리기·힌트·단계/구간/번호 이동을 검사하는 자동 테스트

## 다시 빌드하기

```bash
python3 gen.py         # puzzles.json 다시 만들기 (같은 시드 → 같은 결과)
python3 build.py       # index.html + dashboards/백호-한붓그리기.html 생성
python3 test_app.py    # 자동 테스트
```
